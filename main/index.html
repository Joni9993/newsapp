// oder den flow komplett selbst bauen:
1. "Automate" von LlamaLab aus dem Play Store
2. + → neuer Flow. Der Block "Flow beginning"
   ist schon da.
3. Block "Notification posted?" hinzufügen:
   Proceed: When transition
   Exclude flags: Group summary, Ongoing
   Package: leer = alle, oder App wählen
   Output: Package → pkg · Title → title
           Message → msg
4. Block "HTTP request" hinzufügen:
   Request URL: adresse links (mit token)
   Request method: POST
   Request content type: application/json
   Request content body (fx-Knopf):
   jsonEncode({"app": pkg, "title": title,
               "text": msg})
5. Verbinden: Flow beginning → Notification
   posted? · YES → HTTP request → zurück zu
   Notification posted? · NO ebenfalls zurück
6. Speichern, Start. Automate den
   Benachrichtigungszugriff erlauben und die
   Akku-Optimierung für Automate ausschalten.
